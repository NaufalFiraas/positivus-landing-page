# Positivus Landing Page

A responsive marketing agency landing page built with:
- HTML5
- SCSS/SASS
- Vanilla JavaScript
- Swiper.js

## Features
- Responsive navbar with scroll spy
- Testimonial slider
- Accordion working process
- Contact form with validation
- Toast notification
- Disabled & loading button states
