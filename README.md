# Positivus Landing Page

A modern and responsive marketing landing page built with HTML, CSS, and JavaScript.

## ✨ Features
- Responsive layout
- Interactive sections
- Form validation
- Smooth scrolling navigation
- Active navbar on scroll

## 🛠 Tech Stack

- CSS / SCSS
- JavaScript (Vanilla)
